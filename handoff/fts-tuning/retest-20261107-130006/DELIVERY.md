## 4. 验收结论

**推送和本轮有界测试已完成；候选没有达到整体验收，最高性能状态下本窗口仍未提供小幅优化的可信晋升依据。**

预登记门槛为 9 项指标配对绝对差 <=1%、SELECT 1 <=2%、RSS <=2%，尾延迟 P95 <=5%/P99 <=10%，宿主负载前后 <=15%。当前数据超过门槛。即使用主要收益至少 2% 的要求，IK/Beng 分词波动仍过大。不能据此宣布所有 WSL 环境不可测，也不能认定此前波动已被证实由性能释放不足导致。

追加上限为两对，但第三份追加报告结束时宿主读数 16%，按约定停止，未补第四份；因此合计三对加一份未配对。LoadPercentage 包含测试自身活动与采样窗口影响，不能把该读数直接解释为外部任务负载。关于修正为固定空闲间隔的时序依据见 EXPERIMENT_LOG；具体波动根因仍未知。

`/benchmark` 已发出并回读。收尾检查尚无可见 check run 或 Actions workflow run，也无机器人结果评论。fork 的 SeekDB 工作流有 oceanbase owner 和 master/develop PR base 条件；当前发布/请求不能记为官方 CI 已运行或通过。本轮 Linux 实测结果来自 legion。
