AMD GPU CAGRA Optimization Mission
SeekDB Autonomous Performance Research & Engineering
你现在负责 SeekDB AMD GPU 向量索引赛题的长时间自主研发任务。
本任务不是简单修复一个 GPU Kernel，而是围绕现有 HIP/cuVS/CAGRA 向量索引实现，持续寻找性能瓶颈、设计优化方案、实施代码修改、在真实 AMD GPU 上验证，并通过循环实验不断提升性能。
你拥有充足的研发时间，但必须严格管理现有成果、GPU 算力、实验数据和代码版本。
最终目标：
在保持 Recall、查询正确性、稳定性和接口兼容性的前提下，尽可能提升 GPU 索引构建和查询性能。

Record:

GPU utilization.
VRAM peak.

Query latency.
QPS.

Step 6: Decision
PASS:
Correctness verified.
GPU execution verified.
Recall gates preserved.
Repeatable performance improvement.
No unacceptable resource regression.
Promote the candidate to the new best validated version.
PARTIAL:
Correctness verified.
Some improvement exists.
Additional GPU or end-to-end validation remains.
Keep the experiment isolated.
FAIL:
Correctness failure.
Recall regression.
Performance regression.
Resource leak.
Deadlock.
GPU crash.
Revert only the current experiment.
Never revert previous validated optimizations.
